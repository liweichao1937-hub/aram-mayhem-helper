# 海克斯大乱斗快捷入口

结合 [ARAM Mayhem](https://arammayhem.com/zh-cn/) 使用：本地负责「中文搜英雄」，官网负责完整数据。

## 日常用法

1. 双击桌面 **「海克斯大乱斗助手」**
2. 输入英雄名，按 **回车**
3. 自动打开官网该英雄出装页，同时本页显示海克斯/出装摘要

## 更省事：浏览器书签直达

把下面地址存成书签（可改英雄名）：

`http://127.0.0.1:8765/go?q=艾希`

助手在运行时，打开该书签会立刻跳到官网对应英雄页。
